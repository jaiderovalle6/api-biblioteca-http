# API HTTP de Biblioteca
API construida con Node.js y TypeScript para gestionar libros en memoria.
## Requisitos- Node.js LTS- npm
## Instalación
```bash
npm install
```
## Desarrollo
```bash
npm run dev
```
## Verificación y compilación
```bash
npm run check
```
## Producción local
```bash
npm run build
npm start
```

## Limitaciones
